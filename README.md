# Бот-баннер

Telegram-бот, который принимает от пользователя фото, имя-фамилию и регалии, и
присылает в ответ готовый баннер с этими данными, наложенными на ваш шаблон.

## Как это работает

1. Пользователь пишет боту `/start`.
2. Бот просит фото → имя и фамилию → регалии/должность.
3. Бот накладывает фото (в круглую рамку) и текст на шаблон `assets/template.png`
   и присылает результат картинкой.

## Установка и запуск

Требуется Python 3.10+.

```bash
cd banner_bot
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Токен бота уже вставлен в файл `.env` (тот, что вы прислали в чате). Если хотите
использовать другой токен — откройте `.env` и замените значение `BOT_TOKEN`.

**Важно про безопасность токена:** этот токен был показан в переписке, поэтому
его нельзя считать полностью приватным. Если это боевой бот, а не тест —
зайдите к @BotFather, выберите бота → Bot Settings → API Token → Revoke current
token, и впишите новый токен в `.env`.

Положите свой файл шаблона баннера в `assets/template.png` (замените
`assets/template_placeholder.png`, которая приложена только для примера).

Запуск:

```bash
python bot.py
```

Бот будет работать, пока запущен этот процесс (пока открыт терминал). Чтобы
он работал постоянно (24/7), не завися от вашего компьютера — разверните его
в облаке, см. раздел «Деплой на Railway» ниже.

## Деплой на Railway (чтобы бот работал 24/7)

[Railway](https://railway.com) — облачная платформа, где можно запустить бота
без настройки сервера вручную. Новым аккаунтам дают разовый бонус $5, дальше
доступен бесплатный план ($1 ресурсов в месяц — этого обычно хватает для
лёгкого бота вроде этого, если сообщений немного) либо план Hobby за $5/мес
с большим запасом ресурсов.

1. Зарегистрируйтесь на [railway.com](https://railway.com) (можно через GitHub).
2. Установите Railway CLI (нужен Node.js):
   ```bash
   npm install -g @railway/cli
   ```
3. В папке проекта `banner_bot` (там, где `bot.py`) выполните:
   ```bash
   railway login
   railway init
   ```
   `railway init` создаст новый проект в вашем аккаунте Railway.
4. Задайте токен бота как переменную окружения (а не через файл `.env` —
   файл `.env` в проект загружать не нужно, у него уже есть `.gitignore`):
   ```bash
   railway variable set BOT_TOKEN=ваш_токен_от_BotFather
   ```
5. Запустите деплой:
   ```bash
   railway up
   ```
   Railway автоматически определит Python-проект по `requirements.txt` и
   запустит команду из `Procfile` (`python bot.py`) как фоновый воркер —
   боту не нужен открытый порт, он сам стучится в Telegram.
6. Откройте `railway logs`, чтобы убедиться, что в логах появилось
   «Бот запущен, ожидаю сообщения...», и напишите боту `/start` в Telegram.

Если позже поменяете код — просто повторите `railway up` из этой же папки,
Railway обновит уже созданный сервис.

**Альтернатива без CLI:** залейте папку `banner_bot` в репозиторий на GitHub,
затем в Railway: New Project → Deploy from GitHub repo → выберите репозиторий →
в Settings → Variables добавьте `BOT_TOKEN` → Deploy. Работает так же, просто
через веб-интерфейс вместо терминала.

*(Аналогично можно развернуть на [Render.com](https://render.com) — там нужно
создать Background Worker, подключить репозиторий на GitHub, командой запуска
указать `python bot.py`, и так же добавить переменную `BOT_TOKEN` в Settings.)*

## Шрифт

По ТЗ имя должно быть SF Pro с letter-spacing -5%. Лицензия Apple на SF Pro
запрещает использовать этот шрифт вне интерфейсов/контента под платформы
Apple — маркетинговый баннер под это не подпадает. Поэтому использован
**Inter** (`assets/fonts/Inter-Variable.ttf`, лицензия SIL OFL, можно свободно
использовать где угодно) — по пропорциям и начертаниям он очень близок к SF Pro.
Имя рисуется начертанием SemiBold, регалии — Light, letter-spacing -5% реализован
вручную (Pillow не умеет tracking из коробки), см. `config.LETTER_SPACING`.

Если у вас есть лицензия и файл настоящего SF Pro (.ttf/.otf) — положите его в
`assets/fonts/` и укажите путь в `config.NAME_BLOCK["font"]` /
`config.CREDENTIALS_BLOCK["font"]` (для не-variable шрифта уберите параметр
`weight` и используйte отдельные файлы Regular/SemiBold/Light).

## Настройка расположения фото и текста

Всё вынесено в `config.py`:

- `PHOTO_BOX` — координаты и размер фото, `shape: "circle"` или `"rect"`.
- `NAME_BLOCK` — имя и фамилия (SemiBold), координата `y` фиксированная.
- `CREDENTIALS_BLOCK` — регалии (Light); `y` не задаётся — блок сам встаёт
  под именем с отступом `NAME_BLOCK["gap_after"]`, даже если имя перенеслось
  на 2 строки.

Координаты — пиксели от левого верхнего угла шаблона (`assets/template.png`,
1620×2160). Проще всего открыть его в любом графическом редакторе и навести
курсор на нужные места, чтобы увидеть x, y.

После правки `config.py` перезапустите бота — изменения применятся к новым баннерам.

## Структура проекта

```
banner_bot/
├── bot.py                  # логика Telegram-бота (диалог с пользователем)
├── image_gen.py             # наложение фото и текста на шаблон
├── config.py                # координаты, шрифты, цвета — тут всё настраивается
├── requirements.txt
├── Procfile                  # команда запуска для Railway/Render
├── .gitignore
├── .env                       # токен бота (не публикуйте этот файл и не грузите на хостинг)
├── .env.example
└── assets/
    ├── template.png            # ваш шаблон баннера
    └── fonts/
        ├── Inter-Variable.ttf   # используется для имени и регалий
        ├── DejaVuSans.ttf       # запасные шрифты (не используются в текущем макете)
        └── DejaVuSans-Bold.ttf
```

## Частые вопросы

**Фото/текст съезжают не туда, куда надо** — поправьте координаты и размеры в
`config.py` (`PHOTO_BOX`, `NAME_BLOCK`, `CREDENTIALS_BLOCK`).

**Нужен свой шрифт** — положите `.ttf`/`.otf` файл в `assets/fonts/` и укажите
путь в `config.py`.

**Хочу больше полей (например, отдельно должность и организацию)** — добавьте
новый `State` в `bot.py` (по аналогии с `waiting_credentials`) и новый блок в
`config.py`, аналогичный `CREDENTIALS_BLOCK`.

**После деплоя на Railway бот не отвечает** — проверьте `railway logs`: чаще
всего это неверный `BOT_TOKEN` (проверьте `railway variable get BOT_TOKEN`)
или закончился месячный лимит бесплатного плана (тогда нужно перейти на Hobby,
$5/мес).
